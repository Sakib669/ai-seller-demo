## 3. Non-sitemap, dynamic and gated routes discovered

| Route | Method | Behaviour observed |
|---|---|---|
| `/shop` | GET | Listing with filters: `q`, `category`, `category_id`, `sub_category_id`, `price-from`, `price-to`, `orderBy`, `sort_by`, `per_page`, `page` |
| `/blogs` | GET | Blog list with `?category_id=1..11` and `?page=1..3` |
| `/cart/index` | GET | Cart page (empty state or line items) |
| `/cart/store/{product_id}` | POST | Add to cart (AJAX, JSON `{status,message,data}`) |
| `/cart/update` | POST | Change line quantity (`cart_id`, `quantity`) |
| `/cart/delete` | POST | Remove line (`cart_id`) |
| `/cart/items` | GET | Return cart offcanvas HTML + subtotal/total as JSON |
| `/get-price` | POST | Variant selection → price / SKU / asking-information HTML |
| `/login` | GET+POST | Sign-in form; POST validates email + password |
| `/signup` | GET+POST | Sign-up form → 302 to `/signup/token/verify` |
| `/signup/token/verify` | GET+POST | OTP entry; POST `user_id` + `token`, JSON errors |
| `/token/resend?event=user_signed_up` | POST | Resend OTP; returned 422 "Something went wrong!" during test |
| `/forgot-password` | GET | 500 Internal Server Error — broker/controller failure |
| `/password/reset, /password/email` | GET | 302 → `/forgot-password` → 500 |
| `/logout` | POST | GET returns 405 Method Not Allowed (CSRF-protected POST) |
| `/checkout` | GET | 302 → `/login` (auth middleware) |
| `/dashboard` | GET | 302 → `/login` (customer account dashboard) |
| `/customer/orders` | GET | 302 → `/login` (order history) |
| `/inquires-customer` | GET/POST | Contact/inquiry endpoint, auth-gated (302 → `/login`) |
| `/admin, /admin/*, /manage, /backend/login` | GET | Redirect to `/` (no public admin route) |
| `/backend/` | GET | 403 Forbidden (directory; only public `/backend/*` assets load) |
| `/sslcommerz/success|fail|cancel|ipn (inferred)` | GET/POST | Route pattern exists server-side; unauthenticated calls bounce to `/` |
| `/product-category/*` | GET | Dead links found in product cards → redirect to `/` |
| `/devtools-blocked.html` | GET | Served replacement page by `protection.min.js` when devtools is detected |
